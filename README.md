## Карта регистров

Базовый адрес устройства в тестбенче — `0x7000_0000`.

| Смещение | Регистр | Доступ | Описание |
|---|---|---|---|
| 0x0 | `SIDE_A` | RW | длина стороны A, беззнаковое 32-битное |
| 0x4 | `SIDE_B` | RW | длина стороны B, беззнаковое 32-битное |
| 0x8 | `PERIMETER` | RO | `P = 2 * (A + B)`, младшие 32 бита |
| 0xC | `STATUS` | RO | bit0 `OVF` — периметр не помещается в 32 бита; bit1 `DEGEN` — одна из сторон равна 0 |

- Периметр пересчитывается сразу после записи стороны (комбинационная логика).
- Запись в `PERIMETER`/`STATUS` и обращение по другим смещениям завершаются `pslverr = 1`, регистры не меняются.
- После сброса все регистры равны 0, `STATUS = 0x2` (стороны нулевые).

## Тест

`tb_top.sv` сам проверяет все прочитанные значения и печатает `PASS`/`FAIL` и итог:
значения после сброса, обычные прямоугольники, чтение сторон, нулевые стороны,
граничные значения и переполнение, запись в RO-регистры, неверные адреса,
40 случайных тестов со сравнением с эталонной моделью, сброс во время работы.
